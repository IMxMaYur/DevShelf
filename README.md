# 📚 DevShelf

> A curated collection of projects, APIs, courses, research papers, datasets, tools, templates, and developer resources for students, beginners, and developers.

**Discover → Learn → Build → Ship**

---

## 🌟 What is DevShelf?

DevShelf is an open-source resource library built to help students, beginner developers, and experienced developers discover useful and reliable technical resources in one place.

Instead of searching through hundreds of scattered websites, repositories, articles, and videos, DevShelf brings useful resources together and organizes them by category, difficulty, technology, and use case.

## ⭐ What makes DevShelf different?

DevShelf focuses on **curation and usability**, not simply collecting thousands of links.

Resources are organized using useful information such as:

- Difficulty level
- Technology
- Category
- Use case
- License
- Availability
- Documentation
- Demo availability
- Verification status

The goal is to help you answer:

> **"Is this resource actually useful for what I'm trying to do?"**

## 🏷️ Resource Badges

DevShelf uses badges to make resources easier to evaluate.

| Badge | Meaning |
|---|---|
| ⭐ Recommended | Particularly useful or high quality |
| 🟢 Verified | Resource/link has been checked |
| 🌱 Beginner Friendly | Suitable for newcomers |
| 🔥 Popular | Widely used or highly interesting |
| 🧪 Experimental | Experimental or early-stage resource |
| 🆓 Free | Available without payment |
| 💳 Free Tier | Provides a free tier with possible limitations |

## 📌 Quality over Quantity

DevShelf is not intended to become a random collection of links.

A useful resource should ideally provide:

- A clear description
- A working source
- Useful documentation
- Appropriate categorization
- Clear licensing where applicable
- Enough information for someone to evaluate it

**A smaller collection of useful resources is better than a huge collection of unreliable ones.**

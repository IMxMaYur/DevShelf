# 🤝 Code of Conduct

## Our Commitment

DevShelf is committed to providing a welcoming, respectful, and constructive environment for everyone who participates in the project.

We want DevShelf to be a place where students, beginners, experienced developers, maintainers, and contributors can learn and build together.

---

## Expected Behavior

Participants are expected to:

- Be respectful and professional.
- Communicate constructively.
- Welcome people with different levels of experience.
- Give useful and respectful feedback.
- Focus on improving the project.
- Respect different opinions and approaches.
- Help beginners when possible.
- Give appropriate credit to original authors and sources.

---

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks.
- Insults or deliberately hostile behavior.
- Trolling or intentionally disruptive behavior.
- Threats or intimidation.
- Publishing private information without permission.
- Spam or excessive self-promotion.
- Deliberate submission of malicious content.
- Misrepresenting someone else's work as your own.
- Any other behavior that is inappropriate for a professional open-source community.

---

## Resource Attribution

When contributing resources, respect the work of the original creators.

Do not:

- Claim someone else's project as your own.
- Remove attribution.
- Copy copyrighted material without permission.
- Redistribute material when the license does not allow redistribution.

Whenever possible, link to the original source.

---

## Maintaining a Constructive Community

Disagreements are normal in open-source projects.

When disagreements occur:

1. Focus on the technical issue.
2. Explain your reasoning.
3. Listen to other perspectives.
4. Avoid personal attacks.
5. Work toward a practical solution.

Being technically correct does not justify being disrespectful.

---

## Enforcement

Project maintainers may take appropriate action when behavior violates this Code of Conduct.

Possible actions include:

- Requesting changes to communication.
- Removing inappropriate comments.
- Closing issues or pull requests.
- Temporarily restricting participation.
- Removing a contributor from the project when necessary.

The response will depend on the severity and circumstances of the violation.

---

## Reporting Problems

If you encounter harassment, malicious behavior, or another serious violation of this Code of Conduct, report it privately to the project maintainers rather than escalating the situation publicly.

For security vulnerabilities, use a private security reporting mechanism rather than posting sensitive details in a public issue.

---

## Scope

This Code of Conduct applies to project spaces and interactions related to DevShelf, including:

- GitHub issues
- Pull requests
- Discussions
- Project documentation
- Other official DevShelf community spaces

---

## Final Principle

DevShelf exists to help people:

**Discover → Learn → Build → Ship**

Let's make the project useful, welcoming, and respectful for everyone.

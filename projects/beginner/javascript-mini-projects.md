## 📌 What is this?

A collection of small JavaScript projects designed to help beginners learn frontend development by building practical applications.

The collection includes:

- Counter App
- To-Do List
- Calculator
- Digital Clock
- Weather Web App
- Currency Converter
- Quote Generator
- Text-to-Speech App

---

## 🧠 What you'll learn

- DOM manipulation
- JavaScript event handling
- Browser APIs
- HTML/CSS/JavaScript project structure
- Working with APIs
- Local storage
- Building small frontend applications
- Turning JavaScript concepts into practical projects

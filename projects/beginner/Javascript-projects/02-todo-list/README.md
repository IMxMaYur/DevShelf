# ✅ To-Do List App

A full-featured task manager with priority levels, filter tabs, a live progress bar, and `localStorage` persistence — built with pure HTML, CSS & JavaScript.

**Author:** [IMxMaYur](https://github.com/IMxMaYur)  
**Part of:** [DevShelf JavaScript Mini Projects](https://github.com/IMxMaYur/DevShelf/blob/main/projects/beginner/javascript-mini-projects.md)

---

## ✨ Features

- ➕ **Add tasks** with a name and priority level (Low / Medium / High)
- ✅ **Check off tasks** with a smooth circular checkbox animation
- 🗑️ **Delete tasks** individually with a swipe-out animation
- 🎯 **Priority colour dots** — 🟢 Low · 🟡 Medium · 🔴 High
- 📊 **Progress bar** showing what percentage of tasks are done
- 🔢 **Live counter** — done/total badge in the header
- 🗂️ **Filter tabs** — All · Active · Completed
- 🧹 **Clear Completed** button to remove all finished tasks at once
- 💾 **localStorage persistence** — tasks survive page reloads
- 📅 **Date display** showing today's date in the header
- 🌑 **Dark glassmorphism UI** with gradient background

# 🔢 Counter App

A sleek, interactive counter with an animated progress ring, step control, and action history — built with pure HTML, CSS & JavaScript.

**Author:** [IMxMaYur](https://github.com/IMxMaYur)  
**Part of:** [DevShelf JavaScript Mini Projects](https://github.com/IMxMaYur/DevShelf/blob/main/projects/beginner/javascript-mini-projects.md)

---

## ✨ Features

- ➕ **Increment** and ➖ **Decrement** buttons with smooth bounce animation
- 🔄 **Reset** button with a 180° spin transition
- 🔢 **Step size control** — count by 1, 5, 10, or any custom value
- 🟣 **Circular SVG progress ring** — maps the counter value (0–100) to a gradient arc
- 📜 **Action history** — shows the last 20 operations in a scrollable list
- ⌨️ **Keyboard shortcuts** — `↑` increment · `↓` decrement · `R` reset
- 🎨 **Dynamic colour** — green for positive, red for negative, purple for zero
- 🌑 **Dark glassmorphism UI** with animated background orbs

```
Double-click index.html
```

or right-click → *Open with* → Chrome / Edge / Firefox.

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `↑` or `+` | Increment by step |
| `↓` or `-` | Decrement by step |
| `R` | Reset to 0 |
